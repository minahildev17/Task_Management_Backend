# Task Management Backend

A backend system for managing tasks, users, organizations, projects, comments, attachments, and activity history.

## Tech Stack

- Python
- SQLAlchemy ORM
- MySQL
- Alembic (Database migrations)

## Project Features

- User management
- Organization management
- Project management
- Task management
- Comments system
- Attachments handling
- Activity history tracking

## Database

Database used:

- MySQL

Main entities:

- Users
- Organizations
- Projects
- Project Members
- Tasks
- Comments
- Attachments
- Activity History
